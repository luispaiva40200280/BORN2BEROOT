# BORN2BEROOT
WHAT I NEED TO DO IN THIS PROJECT
🧭 OVERVIEW

Goal:
Create your first secure Linux server from scratch — headless (no GUI), with:

Proper partitioning, encryption, user management, and security policies.

SSH, firewall, and monitoring script.

Full understanding of everything you configure.

You’ll defend it (like an interview): they’ll test your setup and ask theory questions.

🧩 1. PREPARATION & SETUP
🔹 Choose Your OS

You can use:

Debian (recommended if you’re new) → Debian 12 Bookworm (latest stable)

Rocky Linux 9 (for Red Hat–like experience)

💡 For beginners: Choose Debian — clearer documentation, simpler SELinux alternative (AppArmor).

🔹 Virtualization Environment

Use VirtualBox (officially supported) or UTM (on Mac M1).

✅ Download:

Debian ISO: https://www.debian.org/distrib/netinst
